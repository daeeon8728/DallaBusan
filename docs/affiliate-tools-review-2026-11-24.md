## 설정·API·프레임 경계

config/catalog/travel-tools.json과 서버 config/travel-tools.ts만 발급 URL/도메인/추적값·허용 경로·변형 언어·출처를 보관한다. Map은 새 공식 발급 설정으로 갱신했다. 기존 개별 제휴 URL/상품/사진/번역·의존성/.env는 재발급 근거 없이 덮어쓰지 않았다. 공개 임베드 토큰과 비공개 API 인증키를 구별한다.

/api/travel-tools?locale=en은 최소 공개 메타데이터만, /api/travel-tools/:id?locale=en은 현재 사용 가능한 프레임 계약만 반환한다. strict query/ID/HTTPS 호스트·경로·발급 추적값·중복 파라미터·고정 공개 refer origin/path를 검증한다. 브라우저가 URL/CID/파트너 토큰을 주입할 수 없다. 실제 현재 페이지의 검색어/개인 경로를 refer로 보내지 않고 승인된 공개 /travel-tools와 locale만 사용한다. 미승인/비활성 제공처·도구는 비공개이며 server는 외부 예약 API를 호출하지 않는다.

공식 SDK2개를 읽어 iframe 주소와 초기화/레이아웃 프로토콜을 확인했다. 최상위 window에 제3자 스크립트/HTML을 실행하지 않고 cross-origin sandbox iframe으로 대체한다. 새 숙소 검색창의 adjustwidth 초기 메시지와 resize/expand 응답은 정확한 origin과 해당 iframe.contentWindow 모두를 검사한다. 수신 높이는 검증된250~1600px만 허용하고 링크/HTML/상위 탐색/임의 폭을 수신 메시지로 바꾸지 않는다. WindowProxy envelope는 JSON 계약으로 검증한다.

고정320px 검색창은 모바일 컨테이너에 맞춰 비율 축소한다.6개 상품 카드 높이는 공식 SDK 기준808/1132/2318px를 실제 컨테이너 너비에 적용한다. 중첩 상세창에서도 접근성 영역 ID가 겹치지 않게 기존 지도/배너에 useId를 사용한다.
