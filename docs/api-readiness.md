# API·제휴 링크 연동 상태 — 2026-11-10

최신 범위는 AI·예산·일정이 아닌 부산 제휴 상품 소개다. 로그인된 4개 포털을 실제로 확인하고 기존 채널 도구에서 링크를 확보했다. 신규 사이트 제출·계약 동의·키 발급/재발급·금융 정보 변경·예약·결제는 수행하지 않았다. API 비밀값은 기록하지 않는다.

원본 총 393건, 제외 90건, 공개 303건이다. 제외 이유는 config/catalog/exclusions.json에 남겼다. 부산 출발·도착·지역 복합 상품을 부산 내 상품과 구분한다. 기존 채널에서 링크를 발급할 수 있다는 사실은 **새 Trip Fit 웹사이트의 홍보 승인 완료를 의미하지 않는다.** 각 설정의 websiteApproval은 unverified다.

현재 사이트에는 이미 확보한 제휴 링크를 사용할 수 있으므로 로컬 구현을 위해 유료 도메인·임대 서버를 먼저 구매할 필요가 없었다. 공개 운영은 접근 가능한 URL·채널 등록 및 각 파트너의 사용 허용 범위 확인이 남아 있다. 유료 구매가 네 곳 모두의 필수 조건이라고 확인된 것은 아니다.

## 아고다 전체 숙소 데이터 제한

공식 호텔 데이터 페이지에서 메타데이터/이미지 이용 안내와 한국어 전체 ZIP을 확인했다. 기대 파일 크기 466,787,815 byte였지만 Node 스트리밍과 curl 두 방식 모두 upstream이 전송 중 종료했다. 마지막 전송은 63,205,564 byte에서 끊겼다. 부분 파일은 var/imports 아래 격리해 카탈로그에 넣지 않았다. 확인한 개별 숙소 10개와 공식 부산 전체 보기 링크만 제공한다. 모든 부산 숙소 수집 완료로 표시하지 않는다.

## .env와 부산 공공 API

루트 .env 기존 값은 보존한다. 제휴 API 키는 서버 config 전용이며 키 입력만으로 미구현 API가 연결되지는 않는다. 현재 303개 상품은 검수한 파일 스냅샷으로 제공한다. 자동 상품·가격·재고 갱신은 없다.

기존 AttractionService는 루트 .env의 키로 5개 언어 실제 수집을 검증했다. ko 213 / en 207 / ja 208 / zh-CN 208 / zh-TW 208, 합계 1,044개 언어 레코드다. 고유 명소 수가 아니며 아직 미검수다. 현 상품 카탈로그와 별도로 유지한다.

## 공공 관광정보 전체 검색 연결 — 2026-11-11

기존 1,044개 언어 레코드의 원본 ID 그룹 220개를 모두 사이트 검색에 연결했다. API에서 ADDR1을 실제 확인하고 국문 213건/3페이지를 재수집해 주소를 확보했다. data:publish로 안전하게 공개 스냅샷을 갱신할 수 있다. 방문자 검색이 외부 API를 직접 호출하지 않는다.

기존 상품 303개 중 위치/방문 대상이 확인되는 117개를 관광정보 25개와 연결했다(관계 190개). 나머지 관광정보 195개에는 확인되지 않은 예약 링크를 만들어 넣지 않았다. 나머지 상품 186개는 전체 상품 검색에서 계속 제공한다. 제휴 상품 API 어댑터/자동 가격·재고 갱신/신규 웹사이트 승인은 여전히 미확정이다.
