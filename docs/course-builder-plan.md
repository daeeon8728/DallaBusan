# 나만의 코스 만들기 (2026-11-26)

기존 50개 편집 코스를 보존하고 같은 검수 원본에서 인접한 두 장소의 짧은 조합 24개를 추가한다. 원본 순서/ID 지문을 고정하고 공개 여부와 walking 모드·인접한 두 장소·체류 합계 180분 이하·직선거리 2km 이하를 검토한 아이디어다. 현장/동선 승인이나 2km 도보 보장이 아니다.

별도 /build-your-day에서 짧은 코스24/기존50/기존 코스 장소100을 검색·선택하고 최대12개 고유 장소를 순서대로 조합한다. 중복은 추가하지 않고 한 코스 추가가 한도를 넘으면 전부 보류한다. 근처 필터는 마지막 장소에서 다음 코스 첫 장소까지 3km 이내 직선거리만 표시한다. 이동시간으로 환산하지 않는다. 지도는 번호 마커만 표시하며 조합한 구간에 기존 경로를 잘못 이어 붙이지 않는다. 기존 원본 코스의 지도는 별도 상세에서 확인한다.

장소 ID/종류/저장일만 전용 localStorage 키에 자동 저장한다. 저장 실패는 메모리 초안을 유지하고 오류/재시도를 보여준다. 손상 데이터는 명시 초기화 전 보존한다. 다른 탭 변경 충돌 시 초안을 보존하고 자동 덮어쓰지 않는다. 비공개/누락 장소도 저장 ID를 보존하며 예약 링크를 만들지 않는다. 찜/장바구니 저장 키와 분리한다.

선택한 관광지의 명시 검수 상품만 방문 순서대로 하단에 제공한다. 숙소는 마지막 장소와 연결된 stay 관계만 별도 제공하며 실제 상세 재조회·통화·제공처/링크 검증을 유지한다. 서버는 읽기 전용이며 AI·전역 최적화·실시간 교통/영업/대기·예산/내부 결제·공유 서비스를 추가하지 않는다.

작업 순서: 계약·고정 원본 자료 → 읽기 전용 API → 순서 편집과 안전한 저장 → 5개 언어 UI와 지도/상품 → 테스트/빌드/dist smoke/시연 → proof 기록. 검증은 lint/typecheck/test/check:providers/build/data:courses:check 및 모바일/태블릿/PC E2E다. 사진·환율·타일·분석 요청은 대역으로 검사하며 외부 예약은 클릭하지 않는다.
