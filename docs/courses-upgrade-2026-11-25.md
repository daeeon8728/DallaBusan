1. 현재 코스/원문 지문/경로·제휴 설정과 기존 공개 정책을 대조한다.
2. friends 계약·서버 ID/카테고리·5개 언어를 추가하고 기존100개 검수 장소만 명시 연결한다.
3. 추가10개 입력만 공식 FOSSGIS OSRM에서1.5초 간격으로 수집하고 기존40개 경로를 보존한다.
4. 모든50개 상세에 번호별 방문 요약·체류/모델 이동 분리·PC 고정 지도/간결한 장소 카드·접이식 원문을 적용한다.
5. 숙소 검색을 좌우 비교로 분리하고, 동시 열기/개별 닫기·모바일 적층·클릭 전 외부 로드0을 검증한다.
6. source/route check·lint/typecheck/단위/통합·provider 경계·build·E2E·dist start 및 실제 Vercel 패키지를 확인하고 proof에 기록한다.

## 화면·조작

- 큰 세로 커버를 간결한 제목/사진 두 열로 바꾼다. 번호·시작/끝·장소 체류 제안·모델 이동을 먼저 표시한다. 전체 체류를 확정 소요시간으로 합쳐 표시하지 않는다.
- 번호별 요약 버튼은 해당 카드로 이동하고 키보드 초점을 전달한다. 지도 마커 선택과 같은 selected 번호를 사용한다.
- PC1000px 초과는 장소 카드와 sticky 지도를 두 열로 배치한다. 작은 화면은 지도→장소 순서이며360px 가로 넘침을 허용하지 않는다.
- 메뉴·운영시간 미리보기와 사진/주소·길찾기를 간결하게 표시하고 전체 원문/휴무/출처는 펼침으로 보존한다. 가족 주차 안내·관광지/맛집 원래 상세·관련 제휴상품 연결은 유지한다.
- 숙소 검색은 PC/태블릿 두 열,700px 이하 한 열이다. 개별 열기 외에 두 검색창 함께 열기/닫기를 제공한다. 티켓 광고는 별도 영역이다. 지도/배너도 보조 영역으로 분리한다.
- 도구 URL과 CID는 재발급/치환하지 않는다. 영어 검색창 고지·5개 언어 UI·검증된 프레임 경계·안전한 외부 이동·클룩 pending은 유지한다. 두 판매처의 날짜/인원은 사용자가 각각 설정하며 최저가 비교/결과 통합을 주장하지 않는다.

## 위험과 검토

모델 경로는 원본 대표 좌표 기준이며 입구·계단·강풍/우천 통제·예약 시간·주차/행렬을 검증한 일정이 아니다. 송도 도보는 길어질 수 있으며 해안 출입과 체력을 확인한다. 오시리아는 놀이공원 체류를 늘리면 사찰을 다른 날로 나눌 수 있도록 안내한다. 인원 많은 모임의 좌석/메뉴/알레르기는 방문 전 확인한다. 미쉐린/블루리본·짧은 대기·현재 영업·현지인 전용을 새로 보장하지 않는다.

원본 공공 JSON/DB·상품/사진·.env·의존성/lockfile은 변경하지 않는다. 외부 타일/이미지/광고의 자동 검증은 대역이며 실제 예약·검색 제출·결제·광고 클릭을 수행하지 않는다.
