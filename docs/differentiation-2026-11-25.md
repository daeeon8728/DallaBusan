# DallaBusan 차별화 기능 제안 (2026-11-25)

상태: 초기 제안 중 맛집 대안과 한국어 주문·이동 카드를 후속 구현했다. 관광지 현장 카드/오프라인/숙소 권역 추천/출발 전 체크는 아직 아이디어다. 구현 범위와 검증은 restaurant-help-review-2026-11-25.md 및 proof.md를 따른다. 시장 전체에서 유일하다는 조사 결과가 아니라 DallaBusan의 제품 정체성 제안이다.

## 중심 가치

외국인 여행자가 ‘이 코스를 실제로 편하게 다녀올 수 있는가’를 판단하고 현장에서 바로 행동하도록 돕는다. 기존 관광지·맛집 공공자료,편집 코스/경로,주차 안내,검수된 관련 예약 상품과5개 언어를 하나의 사용 흐름에 연결한다.

## 1순위: 부산 현장 카드

관광지·맛집/코스에서 ‘현장에서 보여주기’를 누르면 큰 한글 장소명·주소,메뉴 원문과 선택 언어 설명,전화·운영/휴무·지도/주차 안내를 모은다. 택시 기사나 식당 직원에게 바로 보여줄 수 있다. 장소의 공공 ID와 출처·수집일을 함께 유지한다. 초기에는 원문과 기존 번역을 재사용하고 짧은 추가 문구는 언어 감수를 거친다.

방문 전 탐색에서 끝나지 않고 여행 중 다시 열 이유를 만든다. 찜한 장소에서 접근하면 로그인 없는 기존 저장 기능과도 연결된다. 명함형 이미지/오프라인 저장·새 개인정보 보관·자동 예약을 당연한 포함 범위로 삼지 않는다. 별도 요청으로 범위를 확정한다.

## 2순위: 줄이 길면 가까운 대안 식당

식당 상세에서 사용자가 ‘대기가 길어요’를 선택하면 같은 권역의 비슷한 메뉴/가격 정보가 있는 검수 후보2~3곳을 보여준다. 사용자가 직접 본 대기 상황을 출발점으로 하며,자동 실시간 웨이팅 숫자를 만들지 않는다. 후보의 메뉴·휴무·주소·주차 자료를 한 화면에서 비교해 이동 결정을 돕는다.

기존 음식점 ID·좌표·메뉴를 사용하고 유사 메뉴 묶음은 별도 검수한다. 위치 정보 자동 수집 없이 현재 선택한 식당을 기준으로 시작할 수 있다. 실제 빈 좌석·짧은 대기·알레르기 적합성·현재 영업을 보장하지 않으며 운영 자료의 출처/수집일을 유지한다.

## 3순위: 내 코스에 맞는 숙소 권역

관심 코스2~3개와 도보/렌트카 선호를 고르면 묵기 좋은 권역2~3개와 이유를 보여주고 공통 숙소 조건을 유지해 예약 검색으로 연결한다. 코스의 장소 좌표와 검수된 권역 매핑을 사용한다. ‘이 코스를 여러 번 왕복하는 부담’,‘식사 장소와의 연결’ 같은 설명을 사람이 확인한다.

먼저 대표 코스10개/몇 개 권역으로 검수한다. 새 권역/POI 검색 링크는 각 판매처 공식 도구에서 발급해야 한다. 직선거리를 실제 이동시간으로 만들거나 호텔 입구/무료 주차·최저가를 보장하지 않는다. 이번 부산 도시 전체 검색을 이미 권역별 검색으로 구현했다고 표시하지 않는다.

## 4순위: 코스 출발 전 체크

각 코스에 실외 비중·계단/유모차 검토·식사 휴무/브레이크타임·주차 자료 유무·우천 대안을 묶은 체크표를 만든다. 가족·친구·연인별로 중요한 정보만 펼쳐 보고 원래 코스로 돌아올 수 있게 한다. 장소별 적합성은 공식 자료/운영자·현장 검수 범위를 분리한다.

초기에는 출처가 있는 정적 체크표부터 시작한다. 날씨/경보 연동은 공식 제공처와 운영비·호출 정책을 결정한 후 별도 구현한다. 현재 주차 빈자리·실시간 웨이팅·영업 중·아동/알레르기 안전을 자동 보장하지 않는다. ‘현지인 검수’는 실제 인터뷰/방문 근거가 쌓인 항목에만 쓴다.

## 권장 사용자 흐름과 평가

코스 발견→내 일행에 필요한 현장 정보 확인→관련 관광지/음식점 찜→숙소 권역 선택→한 번의 조건 입력→검증된 제휴 예약 이동. 기능 성과는 현장 카드 재사용,코스에서 관련 장소로 이동,검증된 외부 검색 클릭 같은 집계로 평가한다. 예약 성과는 제휴사 보고서와 구분한다. 방문 날짜·아동 나이·정밀 위치를 분석 도구로 보내는 이벤트를 새로 만들지 않는다.
