# Intent: Trip Fit
Author: Challs. Status: draft.

## Problem — 무엇을 확인하고 싶은지
부산 방문 외국인 관광객의 여행 정보 탐색 부담을 개인화 일정과 예약 상품 연결로 줄일 수 있는지 확인한다.

## Proposed outcome — 완성되면 무엇이 가능해지는지
로그인 후 설문으로 일정을 생성하고, 장소 편집·AI 변경안 적용·숙소 선택에 따라 시간과 동선을 재계산한다.
여행을 여러 개 저장하고 읽기 전용 링크로 공유하며, 숙박·입장권·체험 투어의 외부 제휴 예약 링크로 수익화한다.

## Affected users and systems — 누가, 어떤 환경에서 실행하는지
대만·중국·영어권 관광객을 우선 대상으로 모바일·PC 반응형 웹에서 사용한다.
한국어·영어·중국어 번체/간체·일본어와 언어별 기본 통화 및 별도 통화 변경을 지원하며 Google·Apple 로그인을 사용한다.

## Constraints — 기술 스택(React + PixiJS), 꼭 지킬 조건
React + PixiJS를 사용하고 사진 중심 매거진형으로 구현한다. 부산 1~7일, 숙박 포함 1인 전체 예산을 기준으로 한다.
AI 변경은 확인 후 적용하고 공유는 해제할 수 있어야 한다. 예약·결제는 외부에서 처리하며 관리자 화면은 후속 개발로 둔다.
2026-11-30 발표를 목표로 직접 수집한 데이터와 외부 API를 활용하고, 정보 조회 실패 시 입력 유지·재시도를 제공한다.

## Open questions — 아직 결정 못 한 것
제휴 플랫폼·승인·추적 링크, 초기 데이터 범위, 지도·경로·환율·AI 제공처를 결정해야 한다.
운영 예산·배포 환경, 하루 활동 기본 시간, 공동 숙박비 배분, 공유 숙소 위치의 상세 수준과 발표 필수 시연 범위는 미정이다.
