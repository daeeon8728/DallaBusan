# Intent: Trip Fit
Author: Challs. Status: catalog pivot, 2026-11-10.

## Problem

부산 여행자가 여러 판매처의 티켓·패키지·체험·숙소를 찾는 부담을 줄이고 실제 외부 제휴 예약 페이지로 연결한다.

## Proposed outcome

사진 중심의 부산 여행 상품 사이트에서 카테고리·판매처·검색으로 상품을 탐색하고 상세 내용을 확인한 뒤 발급된 제휴 링크로 이동한다. AI·예산·일정 생성 기능은 현재 사용자 지시로 제외한다.

## Users

부산 여행자와 외국인 방문객. 한국어·영어·일본어·중국어 간체/번체 UI, 모바일/PC를 지원하며 상품 제목 미번역은 원문임을 알린다.

## Constraints

기존 React/TypeScript 프로젝트를 사용한다. 사진 중심 매거진형 UI를 유지한다. 실제 발급/공식 export/검증한 추적 템플릿으로만 링크를 만들고 업체 정보는 중립 provider 설정 경계로 분리한다. 예약·결제는 외부에서 처리한다. API 키는 루트 .env에서 서버 전용으로 읽고 기존 값을 보존한다. 실패 시 마지막 성공 목록과 검색 입력을 유지한다.

AI·설문·예산·동선·여행 저장/공유·인증·지도/위젯·관리자·내부 결제는 현재 범위에 포함하지 않는다. 기존 PixiJS/Leaflet 설치와 공공 API 구현은 보존하되 화면에 미구현 기능으로 노출하지 않는다.

## Open questions

새 웹사이트 채널 허용/승인, 실제 공개 배포 도메인, 상품 갱신 주기/담당, 사진·번역 권리, 아고다 전체 파일 전송 실패, 위치/유효기간이 불명확한 상품의 검수 범위는 운영 확인이 필요하다.

## 2026-11-11 명소 소개 확장

별도 /search 페이지에 '이달의 관광명소' 배너를 제공하고, 명소 소개 → 설명·주소·휴무 → 해당 장소의 검수된 투어·패키지·티켓·체험·주변 권역 숙소 → 기존 제휴 예약 링크 흐름을 추가한다. AI·예산·지도·계정 기능은 계속 범위 밖이다. 공공 API 다국어 수집본에서 선별한 소개 스냅샷과 명시적인 상품 매핑을 사용한다. 공식 월간 선정으로 오인시키지 않으며 추천 월이 끝나면 일반 명소 가이드로 전환한다.

## 전체 공공 관광정보 검색·상품 연결 (2026-11-11)

사용자가 확보한 전체 부산 관광정보를 검색하고 명소 상세에서 확인된 제휴 상품을 연결한다. 현재 수집본 1,044개 언어 레코드의 원본 ID 그룹 220개를 모두 제공한다. 서로 다른 원본 ID를 물리적으로 같은 명소라고 병합하거나, 모든 관광정보에 예약 상품이 있다고 가정하지 않는다. 원본 안내와 편집 검수 상태를 구분한다.

## 2026-11-12 맛집·추천여행 탭

사용자 요청으로 /food와 /recommended를 독립 읽기 전용 탭으로 추가한다. 부산 FoodService 음식점의 대표메뉴·운영시간·주소·연락처와 RecommendedService 테마여행의 소개·교통·휴무·운영시간을 공식 5개 언어 데이터로 제공한다. 사진과 설명은 해당 원본에 있는 자료만 사용하고, 없는 정보·실시간 영업 상태·예약 상품을 만들지 않는다. 서버 종료 후 최신 사용자 재개 요청으로 검증된 산출물 서버와 외부 HTTPS 미리보기를 다시 열었다. 임시 주소는 PC와 서버·터널 프로세스에 의존한다.
