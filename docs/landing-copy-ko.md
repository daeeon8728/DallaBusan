목표 검색어: **부산 여행 코스**

메타 설명: 부산을 방문하는 외국인 여행자를 위한 부산 여행 코스 서비스입니다. 관광지·맛집과 지도 동선을 살펴보고 짧은 코스를 무료로 조합하세요. 체험·숙소 예약은 외부 판매처에서 진행합니다.

---

**부산 여행 코스**, 어디서부터 짜야 할지 막막하다면 달라부산에서 시작해보세요. 부산을 방문하는 외국인 여행자를 중심으로, 가족·연인·친구와 함께 갈 장소를 찾는 여행자를 위한 서비스입니다. 짧은 코스를 살펴보고 원하는 장소를 더하거나 빼며 나만의 하루를 만들 수 있습니다.

## 달라부산에서 무엇을 할 수 있나요?

추천 코스의 장소와 지도 동선을 확인하고 관광지·맛집·관련 체험 상품을 함께 살펴볼 수 있습니다. 해운대 해변·동백섬을 둘러보는 바다 산책이나 광안리 주변의 데이트처럼, 관심 있는 지역과 여행 상황을 기준으로 탐색해보세요.

| 기능 | 이용 방법 |
| --- | --- |
| 코스 탐색 | 가족·데이트·친구·맛집·달라부산 분류에서 코스를 살펴봅니다. |
| 나만의 코스 만들기 | 짧은 코스를 조합하고 장소를 추가·삭제하거나 방문 순서를 변경합니다. |
| 지도 확인 | 선택한 장소의 위치와 방문 순서를 확인합니다. 직접 편집한 순서의 참고선은 실제 도로 경로나 최단 동선 보장이 아닙니다. |
| 로그인 없는 저장 | 관광지·맛집·상품을 찜하고 같은 기기와 브라우저에서 다시 확인합니다. |
| 외부 예약 연결 | 관련 체험·숙소를 살펴보고 판매처에서 예약과 결제를 진행합니다. |

## 어떻게 이용하나요?

1. **코스를 고릅니다.** 관심 있는 지역이나 동행 유형에 맞는 코스를 살펴봅니다.
2. **하루를 조합합니다.** '나만의 코스 만들기'에서 장소를 추가·삭제하고 방문 순서를 정합니다.
3. **지도를 확인합니다.** 장소 위치를 살펴보고 이동 수단·운영시간·예약 필요 여부를 확인합니다.
4. **필요한 상품을 예약합니다.** 연결된 판매처에서 날짜·인원·최종 가격·취소 조건을 확인한 뒤 예약합니다.

## 무료 이용과 월 1,900원은 어떻게 다른가요?

**현재 사이트 이용은 무료이며 구독료를 받지 않습니다.** 월 1,900원은 향후 선택형 유료 요금제로 기획 중인 금액이며, 현재 판매하거나 결제받는 상품이 아닙니다.

| 구분 | 가격 | 현재 상태와 범위 |
| --- | --- | --- |
| 현재 사이트 이용 | 무료 | 코스 탐색·수동 조합·관광지와 맛집 정보 열람·로그인 없는 찜하기를 이용할 수 있습니다. |
| 향후 선택형 유료 요금제 | 월 1,900원 기획안 | 아직 출시·과금되지 않습니다. 제공 기능과 출시 시점은 미정이며, 확정 후 별도 안내할 계획입니다. |
| 체험·숙소 등 여행 상품 | 판매처·상품별 상이 | 현재 무료 이용에 포함되지 않습니다. 외부 판매처에서 확인하고 별도로 결제합니다. |
