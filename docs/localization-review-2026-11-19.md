# 2026-11-19 다국어 콘텐츠 전수 검수

현재 공개 상품302개·관광지220개·음식점 원본 ID538개를5개 언어로 검사했다. 공개 상품 수와 제휴 URL·가격·관찰일, 원본 관광/맛집/추천여행 스냅샷과 DB는 보존했다. 언어 원본이 일부 없는 경우의 기존 원문 대체를 정적 자동 번역 자료로 보완한다. 개별 번역을 사람 검수 완료·공식 번역으로 표시하지 않는다.

## 원인과 수정

- 상품 제목303개 원본의4개 외국어 번역은 이미 존재했다. 판매처 표시명·사진 출처의 상호가 한국어로 고정됐고, 다른 언어를 선택한 직후 이전 카드에서 연 상세가 이전 제목을 유지할 수 있었다. 중립 provider 설정의 localizedDisplayNames와 공통 사진 출처 문구를 사용하고 상세는 현재 locale로 다시 조회·취소/오래된 응답 차단을 적용했다. 기존 영어 원제 상품2개는 한국어 표시명도 추가했다.
- 관광지는 영어13개·일본어12개·간체12개·번체12개의 원본 언어가 빠져 있었다. 공통 주소도 원문 한국어였다. 기존 공식 번역을 먼저 쓰고 빠진 제목·전체 설명·주소·교통/휴무/요금 안내와 섞인 한글 조각을 보완했다. 새로 번역된 이름 검색과 명시적 연관 상품 검색을 연결했다. 다른 ID의 물리 명소를 병합하지 않았다.
- 음식점은 ko536/en532/ja437/zh-CN337/zh-TW285개 원본이었다. 서비스 전체의 고유 원본 ID는538개이며 모든 언어에서 동일538개를 조회한다. 유효한 외국어 이름 뒤의 한글 병기는 제목에서 분리하고 상세의 ‘현지 원문 이름’에서 보존한다. 번체의 잘못 붙은 괄호·한글 이름, 일부 메뉴·운영시간을 보완했다. 없는 메뉴/시간/사진은 생성하지 않는다.
- 추천여행은 기존 외국어 레코드에 섞인 한글 조각만 보완한다. 누락된 추천여행 언어 원본 전체를 이번 작업으로 새로 발행한 것은 아니며 원래의 명시적 fallback 규칙을 유지한다.

## 번역 자료와 안전

config/catalog/content-translations.json에3544개 문자열 번역과 sourceLocale/targetLocale/원문/원문·언어 조합 SHA-256/번역문/작성일/엔진/기계 번역 미검수 상태를 보관한다. 원문과 정확히 일치해야만 적용되며 원문 변경 시 과거 번역을 무조건 재사용하지 않는다. data:refresh/publish 후 npm run data:localization:check로 재검증해야 한다. 원본 파일은 수정하지 않아 내부 테마 원문 fingerprint·검수 상태도 유지된다.

준비 과정에서 공개 원문 문자열만 무료 Google Translate 웹 응답으로 번역했다. 이는 공식 Cloud Translation API 계약/실연동을 구현한 것이 아니며 비공식 웹 인터페이스를 운영 요청 처리에 연결하지 않는다. 키·추적 URL·계정·사용자 입력을 제출하지 않았고 유료 API 호출0이다. 실행 중인 사이트는 외부 번역 서비스를 호출하지 않고 검증된 정적 파일만 사용한다. 준비 캐시/원문과 장문 분할·결과 검증은 var/imports의 내부 작업 자료이며 실행/빌드에는 Python이나 번역 서비스가 필요 없다. 향후 갱신 시 지원되는 번역 제공처나 편집자의 검수 결과를 같은 원문 검증 계약에 넣을 수 있다.

중복된 한글 이름을 삭제해 사실을 숨기는 방식 대신 실제 외국어 이름을 사용하고 원문은 접힌 영역에 보관한다. description 등 기존 외국어 본문에 일부 한글이 있는 경우에는 해당 조각만 보완해 나머지 원문을 유지한다. 자동 번역된 안내에는5개 언어로 고지하며 운영시간/금액/예약 조건을 최신 보장하거나 기계 번역을 사람 승인으로 해석하지 않는다. 모든 외부 텍스트는 React 텍스트 노드로 렌더링한다.
