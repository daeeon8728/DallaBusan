## 화면 및 운영 규칙

- 별도 주차 페이지/지도는 만들지 않았다. 기존 관광지 검색의 펼침 영역에서 이름·한국어 주소 검색, 유료/무료/혼합/미확인 및 공영/민영 필터·페이지 이동을 제공한다.
- 관광지·맛집 상세의 주변 주차장은 검증된 대표 좌표와 유효 주차 좌표의 직선1km 이내에서 최대3건이다. 출입구나 보행거리/시간이 아니며 원본 좌표 없음/모호함/후보 없음은 구분한다. 반경을 임의 확대하지 않는다.
- 각 항목에 원본 이름/주소·요금 분류·확인 가능한 기본 단위/추가 단위·운영시간 원문·총 구획수·이용 조건·자료 기준일을 제공한다. 현재 영업/잔여면수/예약/진입 허용은 보장하지 않는다. 기본·추가·일권을 합쳐 이용요금을 계산하지 않는다.
- 출처·자료 수집일·범위를5개 UI 언어로 안내하고 시설명/주소/운영 원문은 한국어임을 표시한다. 지도는 외부 위치 링크이며 내장 지도/길찾기 API가 아니다.
- 기존 2009~2020년 기준615행 parking.json은 이력으로 보존하고 최신 공개 디렉터리에 합산하지 않는다. 같은 물리 장소를 중복 집계해 범위를 부풀리지 않는다.
- data:parking-directory:refresh가 전체 검증 후 원자 교체하며 실패 시 마지막 성공본을 보존한다. data:parking-directory:check는 API 없이 원본→파생 결과를 재계산한다. 자동 스케줄러는 없다.

명소명·공식 명소 별칭 검색에서는 해당 명소의 대표 좌표 1km 이내 결과도 합친다. 예를 들어 다대포는 원본 주차장명이 몰운대/다대 중앙 등으로 제공돼 단순 이름 검색에서는 빠질 수 있다. 공간 포함임을 화면에 명시하며 보행경로나 주차장 별칭으로 확정하지 않는다.
