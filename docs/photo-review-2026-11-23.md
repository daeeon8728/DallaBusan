## 구현과 재검수 규칙

원본 food.json·관광지 스냅샷·DB·정적 번역·테마 지문·중복 제외 설정을 변경하지 않았다. 서버는 중복 제외 검증 후 명시적 사진 연결을 5개 언어 목록/상세와 한국어 fallback에 일관되게 적용한다. 추천여행의 같은 숫자 ID에는 적용하지 않는다. 대상/사진 원본의 전체 언어 identity fingerprint, 원래 사진 URL, 실제 사진 제공 ID/URL, 제공 데이터셋/라이선스가 달라지면 서버 시작 시 검증 실패로 재검수를 요구한다. 검수 설정 전체는 공개 DTO에 넣지 않는다.

기존 출처·이용 조건 표기를 유지하며 사진 실패 시 각 언어의 사진 없음 안내를 제공한다. 사진은 실시간 운영·예약 가능 여부를 의미하지 않는다.
