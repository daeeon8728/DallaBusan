# 외국인 기본 진입·메인 특가 쿠폰 검수 — 2026-11-23

## 동작과 범위

웹사이트의 주 대상은 부산에 오는 외국인이다. 첫 진입과 잘못된 locale은 기기/브라우저 언어와 무관하게 영어(en)다. 유효한 명시 locale URL은 우선하고 헤더 오른쪽 언어 선택으로5개 언어를 변경한다. 선택 언어는 URL로 보존해 새로고침·홈 브랜드 링크·뒤로/앞으로에도 유지한다. 언어 없는 새 방문은 다시 영어다. 최초 HTML lang/title/description도 영어이며 별도 localStorage/국적 추정은 없다. 기존 공공 API의 기본 언어 계약은 유지하고 UI가 선택 locale을 명시한다.

메인 /의 추천 명소 앞에 Deals & coupons를 배치하고 명소 소개는 아래에 보존한다. 제목·혜택·핵심 조건·예약 기한·확인일·공식 조건 링크·제휴 이동을5개 언어로 제공한다. 쿠폰 코드는 원문 그대로 복사하며 실패 시 수동 선택 안내를 제공한다. 할인은 상품 참고가·환산가·장바구니 합계에서 미리 차감하지 않는다.

- PROVIDER_C: [국내 체험 목록](https://www.myrealtrip.com/main/experiences?routeType=domestic)에 표시된 부산 행사는 검수일 이전에 종료했다. 다른 지역·부산 출발 해외여행을 부산 방문 상품으로 해석하지 않았다. 외국인 참여/통역/해외카드 등 기존 예약 자격이 미검증인185개를 복원하지 않았다.
- 검색 결과 수집일만으로 오래된 코드를 올해 행사로 판단하지 않았다. 블로그 독자 전용 재배포 금지 코드,존재하지 않는 11/31,특정 요일/카드 조건이 불명확한 코드는 제외했다.

## 기간·설정·안전

설정은 서버 전용 config/catalog/promotions.json, 공개 응답은 /api/promotions?locale=en의 최소 DTO다. 업체명/도메인/추적 값은 설정 경계에 둔다. 공식 출처 호스트,기존 공통 validateLink,중첩 목적지와 실제 근거 URL 일치,상품 providerId/externalId/sourceUrl,현재 공개/예약 자격을 검증한다. 새 제공처는 같은 능력 계약과 설정으로 확장하며 제한 제공처의 예약 자격을 일반 쿠폰으로 우회하지 않는다.

공식 예약 기한과 별도로 짧은 reviewExpiresAt을 둔다. 현재3건은 **2026-11-26 00:00 Asia/Seoul**에 재검수 없이는 자동 비공개다. 이 시각을 공식 행사 종료라고 표시하지 않는다. 서버는 비활성·보류·미시작·종료·확인일 미래·재검수 경과를 요청마다 제외한다. Asia/Seoul 날짜는 운영 표시 기준이며 공식 현지 약관/결제 조건을 우선 확인한다. startsOn은 발행 시작일로도 사용하고 공식 개시일 미확인 항목은 검수일 이후부터만 발행한다.

브라우저는 최초·포커스 복귀·60초마다 로컬 API를 다시 읽고 정확한 만료 시각에도 화면을 비운다. 이것은 외부 행사 자동 수집이 아니다. 갱신 실패 시 아직 유효한 같은 언어의 마지막 목록만 유지하고 오류/재시도를 제공한다. 전부 만료되면 확인된 혜택 없음 안내와 기존 상품 탐색을 제공한다.

갱신 담당자는 원문을 다시 열어 시장·기간·대상·최소금액/상한·여행일·수량·재배포 허용·제휴 목적지를 검수한 뒤 설정과 기록을 함께 갱신한다. 근거 없이 재검수 기한만 연장하지 않는다. 신규 계약/계정/사이트 채널 제출,예약/결제,유료 API나 자동 외부 수집은 추가하지 않았다.
