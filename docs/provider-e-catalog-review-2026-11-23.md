## 공통 계약과 표시

- 중립 PROVIDER_E와 기존 registry를 사용한다. 상호·호스트·CID·경로·상품 이미지 근거는 config 경계에만 둔다. 서비스/컴포넌트에는 ID별 분기를 만들지 않는다.
- localizedHrefs는 실제 관찰한 각 언어 원본 URL만 포함한다. 모든 링크에 HTTPS·호스트·경로·단일 필수 CID를 검증하고 externalIdPathPattern으로 같은 원본 상품 ID인지 검사한다. 다른 상품/잘못된 CID/중복 CID/다른 호스트는 거부한다.
- 원어 페이지가 없는 경우 URL을 추측하지 않는다. 원본 링크를 유지하고 다른 예약 페이지 언어를 카드와 상세에 표시한다. 페이지 언어는 가이드 언어·국적별 이용 자격을 보장하지 않는다. 날짜·옵션·언어·국적/연령 제한은 외부에서 다시 확인한다.
-285개 모두5개 표시 언어를 제공한다. 공식 제목을 우선하고 언어 누락/공식 페이지의 미번역은 정적 편집 요약으로 보완했다. provider-e-editorial-titles.json에 원문/해시/대상 언어·machine-unreviewed를 남긴다. 원문 언어+제목의 SHA-256이 바뀌면 재검수를 요구한다. 한국어가 그대로 남은 도자기 체험/일본어 제목 조각/공항 라운지 제목도 보완했다. 운영 요청에서 외부 번역 API를 호출하지 않는다.
- 사진은 같은 원본 ID의 공식 상품 카드에서 가져온다. 원어 카드의 지연 로딩으로 사진 URL이 없던5건은 같은 상품의 다른 언어 카드로 보완했다.36659는 공식 상세 갤러리의 첫 사진을 확인했다. 별도 상품·지역 대표 사진을 대용으로 넣지 않았다. 출처와 수집일은 product-image-sources.json에 기록한다. CDN의 모든 사진 파일 가용성/별도 권리 계약을 보장하지 않으며 기존 실패 대체를 유지한다.
- 공식 카드에 관찰된 원통화 참고가만 기록한다. 옵션별 실제 최저가/최종 결제 금액을 주장하지 않는다. 원래 가격과 선택한 사이트 언어는 별개이며 기존 표시 환율·장바구니 BigInt 합계를 사용한다. 미확인 가격은 null,실제 무료 쿠폰의 관찰 가격0은0으로 보존한다.
