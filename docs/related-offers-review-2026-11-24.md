# 관련 체험·주변 권역 숙소·제휴 위젯 (2026-11-24)

## 현재 요구와 선정

상품 상세 하단은 같은 관광지/유사 체험과 주변 권역 숙소를 독립 섹션으로 제공한다. 기존의 같은 category/scope만으로 채우던 보완 규칙은 폐기했다. 체험에는 숙소를 섞지 않는다.

1. 기존 destinations.json의 명시적인 관광지→상품 연결을 공유하는 비숙소를 먼저 선정한다. 공유 장소 수, 공유 체험 유형 수 순서로 정렬하며 동률은 기존 제공처 우선순위를 유지한다.
2. 같은 관광지 외에는 offer-recommendations.json의 명시 ID로 분류한 같은 체험 유형이며 scope가 같은 경우만 보완한다. 카테고리 일치나 이름 유사도만으로 런타임 연결하지 않는다. 요트/열차/서핑/SUP/쿠킹/반지·향수 공방/사진/야간 관광/교통 수단 등을 구별했다.
3. 유형34개·고유 상품217개는 기존 공식 출처 캡처의 상품 원문에 근거한 편집 분류다. assistant-source-evidence이며 인간/현장 승인·일정 포함 내역 검증이 아니다. 원본 providerId/externalId/titleLocale/title/sourceUrl/category/scope SHA-256과 evidenceUrl이 모두 일치하는 멤버만 적용한다. 원문 변경 시 관련 분류에서 제외한다. 미분류 상품은 관광지 연결이 없으면 빈 목록이 정상이다.
4. 숙소는 해당 상품의 명소 관계에 원래 검수되어 있던 stay 연결만 별도로 표시한다. 정확한 권역명을 함께 보여주고 도보 거리/소요 시간·지리적 최단거리·입구를 보증하지 않는다. 부산 전체 숙소를 가까운 숙소로 추정하지 않는다. 현재 권역 연결은 해운대/남포동 근거를 사용한다.
5. 각 목록 최대6개, 자기 자신·만료·미승인·예약 자격 미검증 제외, 동일 숙소 그룹당1개, 기준 상품의 동일 숙소 그룹 제외를 유지한다. 일반 카탈로그와 동일한 현재 DTO/제휴 우선순위/사진·원가격을 사용한다. 원본/번역/기존 상품 링크는 바꾸지 않는다.

API /api/offers/:id/related는 items[{offer,reason,places}], nearbyStays[{offer,areas}]를 반환한다. reason은 shared-place/similar-experience다.5개 언어의 장소·권역 표기와 기준/빈 상태 안내가 있다. 기존 단일 dialog·고정 X·바깥 여백·Escape·초점·배경 스크롤 복구와 관련 상품 선택 후 새 상세 조회를 보존한다.

## 숙소 지도와 다이내믹 배너

사용자가 추가 제공한 공식 임베드 코드와 위치 선택 답변에 따라, 상품 상세의 숙소 섹션에 ‘부산 숙소 지도’와 ‘제휴 숙소 상품 보기’를 넣었다. 각 버튼을 누를 때만 서버 설정을 조회하고 외부 iframe을 생성한다. 닫으면 iframe을 제거한다. React의 기존 OSM 코스 지도와는 별개의 숙소 광고 도구다.

- 공식 제공 스크립트를 읽어 생성하는 iframe URL/파라미터를 확인했다. 지도는 Map/index, 배너는 Dynamic/index/다. 제3자 JS를 사이트 최상위 window에서 실행하거나 HTML을 주입하지 않는다. 외부 origin의 sandbox iframe만 사용하며 상위 페이지 이동은 허용하지 않는다. fallback 링크는 sponsored noopener noreferrer다.
- config/catalog/stay-map.json과 stay-banner.json만 각각의 발급 값·호스트·언어/통화·설정을 보관한다. 업체/URL/CID별 분기는 컴포넌트·서비스·domain에 넣지 않는다. 기존 상품 제휴 ID1977017, 제공한 지도 CID1980996, 배너 CID1980997은 서로 다른 발급 설정이므로 통합/교체하지 않는다.
- 배너 코드의 ApiKey는 공식 초기화 코드가 브라우저 iframe URL의 apikey로 전송하는 공개 임베드 발급 식별값이다. 비공개 예약/결제 API 인증키로 사용하지 않는다. 운영 비밀키를 이 파일/공개 DTO에 추가하면 안 된다. 루트 .env의 기존 비밀 값은 변경/공개하지 않았다.
- 지도 중심은 제공된35.179953/129.075236, 부산 시청 인근이며 searchRadius=5 설정을 보존한다. 현재 상품의 명소를 따라가는 지도나 검수된 가까운 숙소 목록으로 표시하지 않는다. 지도 검색 날짜는 서버의 Asia/Seoul 오늘+1일 체크인,6박 체크아웃, 성인2/객실1의 제공된 기본 조건을 표시하고 판매처에서 바꾸도록 안내한다. 과거 고정 날짜로 굳히지 않는다.
- 배너는 제공한300×300/자동 전환3초/검색창 숨김/discountonly=false 설정이다. 좁은 모바일에서는300px iframe을 컨테이너 너비에 맞춰 비율 축소한다. prefers-reduced-motion에서는 자동 전환을 끈다. 해당 관광지 근처/할인 전용/최저가 배너라고 표시하지 않는다. 배너 가격을 카탈로그·장바구니에 수집/차감하지 않는다.
- /api/stay-map은 locale/mobile, /api/stay-banner는 locale/motion만 허용한다. URL/CID/토큰/가격/날짜를 브라우저 쿼리로 덮어쓸 수 없다. 서버가 설정된 HTTPS 호스트를 검증하고 발급된 최소 공개 DTO만 반환한다. 제공처 disabled/unapproved 시404, 모두 no-store이며 서버는 외부 예약 API를 호출하지 않는다.
- en/USD,ko/KRW,ja/JPY,zh-CN/CNY,zh-TW/TWD를 유지한다. 버튼 전 외부 요청/빈 iframe0, 오류 재시도·지도/배너 닫기·새 창 대안을 제공한다. 위젯 실재고/가격은 제공처가 렌더링하며 내부402개 상품 수에 포함하지 않는다.

## 검증 경계

단위 검사는 관련도·비숙소/숙소 분리·단순 category 보완 차단·원문 지문 변경·5개 언어·실제 숙소 그룹/제공처 우선순위, 위젯 발급 값/호스트/언어/통화/날짜/모션/400·404/no-store를 검증한다. 브라우저는3개 화면에서 분리 목록·상세 전환·수동 외부 로드·오류/재시도·모바일 배너 비율·관련 카드 유지·5개 언어를 검증하며 실제 외부 iframe/이미지/GTM은 대역이다.

실제 공식 스크립트와 지도/배너 HTML 각각1회의 HTTP200·프레임 차단 헤더 없음은 확인했다. HTML 응답과 실제 숙소 데이터/파트너 도메인·채널 승인을 구분한다. 새 계약/채널 제출/계정 변경/예약·결제는 하지 않는다. 자동 숙소 수집/실시간 가격 보장도 추가하지 않는다. 정확한 명령·배포 확인과 시연은 proof.md에 기록한다.


## 다이내믹 배너 초기 설정 프로토콜 보완

공식 init-dynamic_v8 초기화는 iframe URL 생성뿐 아니라 load 후 WindowProxy 메시지2개(reloadSetting, edit width)를 전달한다. 별도 제3자 최상위 스크립트 실행 대신 서버가 검증한 initialMessages와 frameName을 공개 DTO로 제공하고, React가 지정 iframe에만 JSON 문자열 envelope를 전달한다. source/target origin·창 이름을 포함하고 postMessage 대상 origin은 실제 설정 URL의 정확한 origin이다. 임의 수신 메시지/resize/URL로 페이지를 바꾸지 않는다. 모션 감소는 URL과 초기 메시지의 isAutoPlay 양쪽에 적용한다. 테스트 iframe이 받은 메시지·출처·이름·순서·수량을5개 언어로 검증한다.


## 실제 외부 배너 상태

최종 배포에서 정확한 발급 URL과 초기 메시지 전달을 적용한 뒤에도 현재 제공처는 일반 FIND YOUR NEXT HOTEL/Book now 배너를 반환한다. 임베드 자체 표시와 호텔별 순환 카드·재고/가격 노출을 구분하며 후자는 미확인이다. 지도는 실제 지도/검색 UI 표시를 확인했지만 호텔 핀·전체 재고·예약 완료를 검증한 것은 아니다. 새 채널 제출/발급 값 변경/계약 동의 없이 이 상태를 보존한다. 상세 관찰은 proof.md를 따른다.
