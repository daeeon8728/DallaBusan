# 저장소에 포함하는 파일

2026-11-26 정리 기준: 새로 내려받은 폴더에서 설치·빌드·실행·데이터 검증과 유지보수를 이어갈 수 있는 파일을 보관한다.

- `apps/`, `packages/`: 실제 프런트엔드·서버·공유 계약과 운영 이미지.
- `config/catalog/`, `data/snapshots/`: 검증된 공개 상품·관광지·맛집·코스·주차 데이터와 읽기 전용 복원 DB. 용량이 크더라도 실행 의존성이므로 유지한다.
- `scripts/`, `tests/`, 설정·lockfile: 데이터 갱신·회귀 검증·재현 설치와 배포에 필요하다.
- `AGENTS.md`, `README.md`, `docs/`의 요구사항·설계·검수 기록: 운영 근거와 다음 개발에 필요하다. 과거 제약은 최신 사용자 결정과 함께 해석한다.
- `.env.example`: 비어 있는 환경 변수 양식만 보관한다.

## Git에서 제외하는 파일

- `docs/screenshots/`의 과거 브라우저 캡처와 smoke 결과.
- `docs/design/`의 PNG/JPG/WebP 시안·검증 캡처와 smoke JSON. 실제 적용한 팝업·로고 이미지는 `apps/web/public/`에 유지한다.
- 루트 `26-11-05 intent.md`: 현재 `docs/intent.md`보다 오래된 기획 초안이다.
- 의존성·빌드 산출물·테스트 보고서·로컬 환경 변수·실행 DB·관리자 비밀번호/세션·로컬 배포 연결 정보.

위 로컬 파일은 삭제하지 않고 Git 추적만 해제한다. 이전 `docs/proof.md`의 캡처 경로는 당시 로컬 증거 경로이며 새 clone에 포함되지 않을 수 있다. 자동 테스트 소스와 텍스트 검수 기록은 계속 제공한다.

이번 정리는 현재 브랜치의 파일 목록에 적용한다. Git 과거 이력을 재작성하거나 이미 공개된 비밀 값을 숨겼다고 주장하지 않는다. 운영 키는 항상 Git 밖에서 별도로 전달한다.
