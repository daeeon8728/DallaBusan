# 맛집 대안·현장 카드 / 홈 코스·영문 지도 검토 (2026-11-25)

## 적용 범위

최신 사용자 요청으로 대안 식당·한국어 주문/이동 카드, 코스 우선 홈, 코스 관련 티켓·체험, 영문 배경 지도를 추가한다. AI·자동 일정 재생성·내부 결제·실시간 웨이팅을 추가하지 않는다. 기존 50개 공개 편집 코스와 내부 17개 테마의 사람/현장 검수 상태는 유지한다.

## 식당 도움말

- `GET /api/food-assistance/:id?locale=en&course=fa06`는 읽기 전용/no-store이며 외부 API를 호출하지 않는다. 음식점 namespace만 처리한다.
- 공공 원본 food.json의 메뉴를 직접 대조한 10개 메뉴 묶음/62개 ID다. 5개 언어 전체 원본 레코드 SHA-256, 정확한 메뉴 인용, 한국어 선택 메뉴가 일치해야 묶음에 참여한다. 사람·현장 검수 완료라는 의미는 아니다.
- 동일 묶음·명시 권역·현재 공개 자격을 만족하는 후보 중 대표 좌표 직선거리 25m 이상/2,500m 이하에서 가까운 3곳까지 제공한다. 25m 하한은 중첩 대표 위치를 보수적으로 제외하는 장치이며 거리만으로 다른 가게임을 증명하지 않는다.
- 영도와 도심, 광안리와 해운대 회 식당의 수역을 가로지르는 일부 조합은 권역으로 분리한다. 모든 후보의 도보 접근성·통행·주차 입구를 검증한 것은 아니다.
- 5개 언어 각각 공개 상태 514곳, 한국어 원문 카드 512곳, 대안 후보가 있는 식당 48곳이다. 62곳 중 14곳은 현재 거리/권역 내 후보가 없어 빈 상태다. 그 밖의 미검토 식당에 유사 메뉴를 자동 추정하지 않는다.
- food:2261/2262는 한국어 원본이 없어 카드 준비 중을 명시한다. 원본 메타데이터 이름을 가공하거나 외국어 주소를 한국어 원문처럼 표시하지 않는다.
- 코스 ID가 실제 선택 식당을 포함할 때만 다음 장소 맥락을 제공한다. 가까운 3개 후보 안에서 다음 장소까지의 직선거리 비교가 가능하다. 최적화/도보시간이 아니며 원래 코스·지도는 수정하지 않는다. 대안 식당 상세로 이동하면 그 식당을 포함하지 않는 코스 맥락은 재사용하지 않는다.
- 한국어 카드: 이름/주소와 택시 문구, 검토한 메뉴 1개·희망 수량 1~10, 덜 맵게/포장 질문, 한국어 원문 전체 메뉴. 주문 수량을 인분·최소 주문·가격으로 확정하지 않는다. 미검토 메뉴는 원문만 보여준다.
- 카드 복사 실패는 명시하며 Close/Escape/바깥 클릭·Tab 순환·초점 복귀·배경 스크롤 복구를 제공한다. 음식/수량/주소를 localStorage·URL·DB·분석 이벤트에 새로 저장하지 않는다. 메뉴 설명은 보조 번역으로 직원 확인을 안내한다.
- 현재 영업·짧은 줄·빈자리·아동/알레르기 적합성·현지인 방문 여부를 추정하지 않는다. 가격은 기존 공공 메뉴 텍스트만 표시하며 통화 환산/합계에 넣지 않는다.

## 첫 화면과 구매 흐름

홈 첫 콘텐츠를 3개 코스 미리보기로 바꾼다. 기본은 가족/데이트/맛집 각1개이며 가족·데이트·친구·맛집·dallaBusan 탭에서 해당 범주의 3개를 살펴보고 전체 코스로 이동한다. 사진→방문 순서→경로/관련 티켓으로 이어진다. 기존 검색·쿠폰·명소 배너·전체 상품과 상단 메뉴·첫 방문 팝업은 유지한다. 기존 검색은 코스 아래 보조 영역으로 이동한다.

`GET /api/courses/:id/offers?locale=en`는 공개 중인 코스의 관광지 ID를 기존 DestinationService의 검수 관계와 대조해 비숙소 티켓/체험/투어를 최대12개 제공한다. 동일 상품 ID를 중복 표시하지 않고 각 상품은 원래 출처·가격·제휴 정책을 유지한다. 숙소는 기존 별도 영역으로 보존한다. 관련 상품이 없으면 준비 상태이며 임의 상품을 끼워 넣지 않는다. 상품 클릭은 기존 최신 상세 재조회/외부 예약 고지를 재사용한다. 여러 상품을 묶은 패키지/코스 전체 가격으로 표시하지 않는다.

## 영문 지도

React-Leaflet의 지도·번호 핀·OSRM 스냅샷 경로는 유지한다. 배경만 OpenFreeMap Liberty 벡터 스타일 + MapLibre GL Leaflet 계층으로 렌더링한다. API키/카드/계정 등록 없이 공개 인스턴스를 사용하며 새로운 비밀키는 없다.

지명 텍스트는 name:en → name:latin → 빈 문자열 순서다. 영어가 없는 지명을 임의 번역하거나 한국어를 영어로 표시하지 않는다. 도로 번호(ref)와 비문자 레이어는 유지한다. UI 언어와 별도로 배경 지명은 영문/로마자를 우선한다. 코스 핀의 설명은 선택한 UI 언어를 유지한다. WebGL/서비스 오류는 안내와 재시도를 제공하고 경로/번호/목록을 보존한다.

지도 코드는 코스 진입 때만 지연 로드하며 Vite가 worker를 같은 사이트의 정적 자산으로 빌드한다. 수집 CLI·서버에서 지도 타일을 내려받거나 라우팅을 재계산하지 않는다. 테스트는 대역, 별도 시연만 실제 공개 지도를 사용한다. 오프라인/타일 선취/새 위치 추적은 없다. OpenMapTiles·OpenStreetMap 저작자 표시를 유지한다. 공개 지도 SLA와 모든 POI 영문 이름 제공을 보장하지 않는다.

## 항공권 판단

Trip.com 공식 제휴 안내는 항공권을 지원한다. 다만 현재 계정의 항공권 수익 조건·실제 발급 URL·날짜/출발지 파라미터는 별도 확인이 필요하다. 항공 검색은 향후 여행 준비의 보조 기능으로 검토하며 이번에는 임의 추적 링크나 항공 가격·예약 UI를 추가하지 않는다.

## 파일과 검증

domain food-assistance.ts/course-offers.ts → 서버 config/service/route 및 runtime → 웹 FoodAssistance/HomeCourses/CourseBookings/EnglishBasemap/i18n/CSS 순서다. `npm run data:food-assistance:check`로 매핑/지문·전체 공개 상태를 재계산한다. lint/typecheck/test/check:providers/build, 관련 E2E, dist 실행과 실제 영문 지도 시연 결과는 proof.md의 최신 절에 기록한다.

공공 원본·DB·번역/사진 오버라이드·공개 제외·제휴 발급 링크는 변경하지 않는다. 외부 실시간 식당 API/포털 수집·추가 상품 수집은 0건이다. 의존성 추가는 maplibre-gl 6.19.0 / @maplibre/maplibre-gl-leaflet 0.1.4이며 lockfile을 갱신했다.
