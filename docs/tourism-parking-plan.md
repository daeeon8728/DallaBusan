# 테마여행·공영주차장 API 활용 실행 계획

작성일: 2026-11-14 (Asia/Seoul). 현재 서비스 표시 브랜드는 dallaBusan이며 내부 프로젝트 ID는 Trip Fit이다. 기준: [intent.md](intent.md), [spec.md](spec.md), [catalog-plan.md](catalog-plan.md), [AGENTS.md](../AGENTS.md). 이 문서는 **향후 코스 추천을 위한 계획**이다. 이번 구현은 서버 설정과 인증 확인까지다.


> 최신 구현 상태(2026-11-14): 아래 최초 계획의 단계1~2(전체 수집·정규화/품질 집계)를 완료했다. 현재 615건을 관리기관+관리번호 복합키로 보존하며 자동 코스 추천·페이지는 미구현이다. 세부 계약과 실제 제한은 이 문서 마지막 구현 절 및 [proof.md](proof.md)를 따른다. 최초 계획의 설정/단건 상태는 이력이다.

## 2. 공식 API 계약과 확인 결과

### 2.1 테마여행

- 서버 기준 URL: https://apis.data.go.kr/6260000/RecommendedService/
- 엔드포인트: ko=getRecommendedKr, en=getRecommendedEn, ja=getRecommendedJa, zh-CN=getRecommendedZhs, zh-TW=getRecommendedZht.
- 서버 키: RECOMMENDED_SERVICE_KEY. 기존 apps/server/src/config/guides.ts의 GUIDE_SOURCES와 env.ts의 loadGuideApiConfig('recommended')를 재사용한다. 같은 서비스를 중복 어댑터로 만들지 않는다.
- 요청: ServiceKey, resultType=json, pageNo, numOfRows. 목록 결과의 UC_SEQ, MAIN_TITLE, TITLE, CATE2_NM, LAT/LNG, PLACE, ADDR1, TRFC_INFO, 운영·휴무·요금·이미지·ITEMCNTNTS를 사용한다.
- 응답 외피는 getRecommendedKr 등 언어별 키 아래 header.code / item / totalCount이다. 주차장 외피와 공용이라고 가정하지 않는다.
- 이번 국문 pageNo=1/numOfRows=1 호출: HTTP200, header.code=00, totalCount=252, 초량이바구길 원본 ID58 확인. 기존 전체 수집본은 ko252/en238/ja233/간체234/번체234, 총1,191개 언어 레코드다. 이번에 외국어 전체 목록을 재수집한 것은 아니다.
- 공식 안내: [부산테마여행정보 서비스](https://www.data.go.kr/data/15063506/openapi.do). 코스 추천 템플릿으로의 변환 규칙은 아래의 프로젝트 설계 결정이며 API가 완성 경로를 보장한다는 뜻이 아니다.

### 2.2 공영주차장

- 서버 기준 URL: https://apis.data.go.kr/6260000/BusanPblcPrkngInfoService/
- 실제 메서드: getPblcPrkngInfo. 전체 호출 경로는 기준 URL과 메서드의 조합이다.
- 서버 키: PARKING_SERVICE_KEY. apps/server/src/config/parking.ts의 PARKING_API_SOURCE와 env.ts의 loadParkingApiConfig()에 고정 HTTPS 원본과 제한을 보관한다. 사용자 입력 URL을 받지 않는다.
- 요청: ServiceKey, resultType=json, pageNo, numOfRows. 영문/일문/중문 메서드는 공식 계약에서 확인되지 않아 생성하지 않는다.
- 이번 실제 응답: HTTP200, response.header.resultCode=00, response.body.totalCount='615'; items.item 배열과 pageNo/numOfRows는 response.body 아래에 있다. 숫자가 문자열이므로 unknown부터 정수/날짜/좌표 스키마로 검증한다.
- 공식 안내: [공영주차장 정보 조회](https://www.data.go.kr/data/15004683/openapi.do), [공식 카탈로그 메타데이터](https://www.data.go.kr/catalog/15004683/openapi.json). 제공처·이용허락 범위·실시간 갱신 표시는 출처 메타데이터이며 개별 레코드의 현재 영업/잔여면수까지 확인한 결과는 아니다.

| 원본 필드 | 후속 정규화/활용 | 해석 제한 |

## 3. 추천에서의 역할 분담

### 테마여행: 추천 이야기와 검수된 방문 순서

테마/권역/언어별로 후보 템플릿을 찾고, 소개·사진·교통 안내를 보여주는 근거로 쓴다. API의 PLACE/ITEMCNTNTS가 자연어·HTML이므로 문자열 분할 결과를 실제 방문 순서나 경로라고 확정하지 않는다. 원문을 근거로 사람이 검수한 orderedStopIds와 sourceExcerpt를 별도 파일에 저장한다.

각 코스 템플릿은 templateId, sourceService, sourceId, sourceLocale, sourceUpdatedOrFetchedAt, verifiedStopIds, optionalStopIds, orderEvidence, themeTags, areaTags, reviewStatus를 가진다. 장소는 관광명소·음식점 등 서비스와 ID로 구분하고, 서로 다른 API의 숫자 ID를 동일 장소로 간주하지 않는다. 원본 제목·좌표·검수된 별칭과 명시적 매핑으로만 연결한다. 기존 언어간 원제목/좌표 검증은 유지하며 외국어 전용 ID는 무리하게 병합하지 않는다.

### 주차장: 자동차 이용 구간의 부가 후보

이동수단이 자가용/렌터카인 경우에만 방문 권역에 주차 후보를 연결한다. 대중교통·도보 코스에 주차장을 필수 경유지로 넣지 않는다. 한 권역에서 여러 장소를 도보로 묶어 방문할 때는 주차 한 번 + 검증된 권역 내 방문 흐름을 우선 검토한다. 공공 API의 지도상 좌표를 진입로·주차 입구 위치로 단정하지 않는다.

주차 후보의 역할은 주변 공영주차장 안내다. 자리 예약·차량 진입 가능·장애인 전용 이용 가능·잔여면수 확보를 보장하지 않는다. 동선에 실제로 편입하려면 주차장 입구, 보행 연결, 운영/부제/차량 조건과 다음 이동을 검증해야 한다.

## 4. 후속 처리 흐름과 구체 규칙

1. 사용자가 날짜·방문 권역·테마·이동수단을 선택한다. 이 입력 UI도 이번에는 만들지 않는다.
2. 검수 완료된 테마 템플릿에서 방문 장소 후보와 순서 근거를 가져온다. 사람이 검수하지 않은 자연어 코스는 소개 자료로만 쓴다.
3. 선택 언어 소개를 붙이고, 누락 번역은 원문/제공 언어를 표시한다. 주차장 API는 한국어 원문으로 유지하고 5개 언어 UI 라벨을 별도로 번역한다. 자동 번역은 별도 제공처·권리·비용 결정 후 검토한다.
4. 운전 구간이면 유효 좌표의 주차장을 탐색한다. 아래 거리 기준은 프로젝트 초안 정책이며 공식 API 조건이 아니다.
5. 방문 시간에 맞는 운영 여부를 확인한다. 미확인 조건은 unknown 상태로 남기고 확정 경로의 필수 주차장으로 채택하지 않는다.
6. 후보를 선택/비교하고, 확인된 제휴 관계만 상품 서비스의 기존 검증 DTO로 연결한다. 테마·주차 정보를 근거 없이 새 판매 상품으로 만들지 않는다.
7. 추천 제공 직전에 기준일/휴무/잔여면수의 신선도를 확인하고, 실패/미확인 상태와 대체 후보를 알려준다.

### 주차 후보·거리·신선도 초안

- 1차 공간 후보는 유효한 위경도 기준 직선거리1km 이내, 최대3개를 제안한다. 없으면 범위를 자동 확장해 가까운 주차장이라고 표시하지 말고 '검증된 근처 후보 없음' 상태를 반환한다. 검색 반경·최대 수는 서버 설정으로 분리하고 운영 검토 후 조정한다.
- 직선거리는 후보 선별 근거일 뿐 실제 도보거리/시간이 아니다. 확인된 라우팅 제공처가 없으면 보행/차량 ETA를 생성하지 않는다. 바다·언덕·철도·단절 도로를 건너 가까워 보이는 오류를 검수한다. 지도 필요 시 기존 Leaflet/OSM 원칙을 유지하되 경로 API를 이미 가진 것으로 취급하지 않는다.
- 요금은 이번 단계에서 안내 원문으로만 보존한다. 계산은 추후 시간 단위·평일/휴일·일권 적용·할인·반올림 규칙을 확인한 뒤 별도 승인 범위로 한다. 예산 기능을 재개하지 않는다.
- 운영시간이 불명확하면 unknown, 명시적 운영 종료/부제 제한이면 ineligible, 기준일이 오래되거나 없으면 unverified다. eligibility와 추천 순서를 분리해 유리한 거리 점수가 불확실한 조건을 덮지 않게 한다.
- 운영·요금 원본 기준일이30일보다 오래되거나 없으면 '운영자 확인 필요'로 분류한다. 30일은 보수적 프로젝트 초안이며 실제 유효기간을 뜻하지 않는다. 재수집으로 이 경고를 지우지 않는다.
- 정적 수집은 주차장1일/테마7일 간격을 운영 초안으로 삼되, 현재 자동 실행은 없다. 실제 쿼터와 갱신 패턴을 확인한 후 결정한다. 실패 시 마지막 성공 스냅샷을 제공하되 collectedAt와 오래됨을 표시한다.
- currava는 필드가 존재한다. 그러나 샘플에는 관측시각이 없고 값도 '-'였다. 독립 관측시각·갱신 간격·쿼터를 확인하기 전 빈자리로 추천 순위를 보정하지 않는다. 이후 확인되면 관측 후60초 이내 표시를 후보 정책으로 검토하되 60초가 공식 보장이라고 쓰지 않는다. null을0으로 바꾸지 않는다.
- 입차/출차 시간이 자정을 넘거나 연휴·일요일·공휴일이 겹치면 한국 시간/공휴일 판별 근거가 필요하다. 현재 별도 달력 API가 연결돼 있다고 가정하지 않는다. 00:00~00:00과 실제24시간 운영은 검수 규칙으로 구분한다.
- 최종 후보 정렬은 자격/검수 상태 → 확인된 보행거리 → 거리 미확인 시 직선거리 → 원본 ID 순으로 결정적 처리한다. 제휴 수수료를 주차장 적합성의 근거로 쓰지 않는다.

## 8. 이번 검증과 상태 보고 위치

실제 호출은 각1건이며 주차장 전체615건을 수집/정규화한 상태가 아니다. [proof.md](proof.md)의 2026-11-14 절에 변경 파일·실행 명령/결과·실패/미실행 항목을 기록한다. API 사용 계약·실시간 잔여면 보장·현장 운영시간·차량 제한에 대한 운영자 확인을 빌드 성공으로 대체하지 않는다.

### 호출량을 확정할 때의 추가 조건

공영주차장 공식 요청 항목에서는 개별 관리번호 조회나 언어 파라미터를 확인하지 못했다. 이를 임의로 만들지 않는다. 전체 갱신1회 호출 수는 ceil(totalCount/검증된 numOfRows)로 계산한다. 615건·100행이 실제 허용된다면7회지만, 이번 표본 요청은1행이므로100행 지원/상한을 먼저 검증한다. 잔여면수 갱신을 후보마다 전체 재수집으로 구현하지 말고 서버 공유 캐시·요청 합치기·일일 쿼터 여유를 설계한다. 쿼터 안에서 관측시각을 확인할 수 없으면 잔여면 추천 기능은 이월한다.

## 2026-11-15 테마 코스 템플릿·장소 연결 구현

사용자 승인 범위는 화면 없이 내부 코스 자료를 구조화하고 원문 방문 순서를 검증하는 단계다. 상세 결과는 [검수 보고서](theme-route-review-2026-11-14.md), 계약·CLI는 [운영 절차](operations.md)의 최신 절을 따른다. 기존 공공 소개/상품 화면과 공개 API는 그대로 유지한다.

테마 원본402그룹/1,191언어 레코드 전체의 coverage를 기록하고, 16개 원본 그룹에서17개 템플릿을 선별했다. 원문 순서 확인15개, 장소까지 확인한 부분 템플릿1개, 검토 대기16개, 연속 구간8개다. 관광지 연결35회·맛집 방문 연결2회, 별도 맛집 후보19개(원문 언급2/직선1km 후보17)를 확인했다. 연결 횟수는 고유 물리 장소 수가 아니다. 미선별386그룹과 미해결43개 방문 노드를 숨기지 않는다.

모든 템플릿은 assistant-source-evidence의 원문 대조이며 humanApproval=pending, fieldValidation=not-performed, recommendationEnabled=false다. 원문·장소 fingerprint 변경 시 기존 승인을 재사용하지 않는다. 불명확한 별칭·복합 장소 좌표·본관/별관은 보류한다. 맛집 후보는 방문 순서에 삽입하지 않으며 직선거리를 이동시간으로 바꾸지 않는다. 사람·현장 검수, 주차 후보, 실제 길찾기, 자동 추천·UI는 후속 범위다.
